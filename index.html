使用说明

三步开始用
  1. 把电子发票 PDF 拖进页面虚线框（可一次拖多个）
  2. 发票信息自动填入表格，识别结果可直接修改
  3. 点「导出 CSV」存成 Excel 文件，或框选表格后 Ctrl+C 直接粘贴
表格怎么操作
  • 修改内容：双击单元格进入编辑（底色变黄），改完自动保存；编辑中单击其他格即切换选中，按 Esc 退出编辑
  • 金额输入：结束自动变千分位格式；输入全角逗号「，」句号「。」会自动转换，超大金额也不会丢失精度
  • 复制：按住左键拖动框选（或点起始格后 Shift+点结束格）→ Ctrl+C → 粘贴进 Excel/WPS
删错了怎么办
  • 点「删除」后 10 秒内页面顶部会浮出撤回条，点「撤回」即可恢复
  • 连续删多条也每条独立计时、独立撤回，恢复后仍按原来的顺序排列
到税务局网站查验真伪
  1. （首次只需一次）先安装浏览器扩展 Tampermonkey（篡改猴）：从官方网站下载安装，或在 Chrome / Edge 浏览器的「扩展应用商店」里搜索 Tampermonkey 安装
  2. 点顶部「查验脚本」按钮 → 一键复制源码 → 点浏览器工具栏的篡改猴图标 →「添加新脚本」→ 粘贴源码 → 按 Ctrl+S 保存
  3. 点表格里的「查验」：自动打开发票查验平台，并填好号码、日期、金额
  4. 输入图片验证码，点「查验」看结果
没装篡改猴脚本也能查验：点「查验」仍会打开发票查验平台，只是需要手工填写发票信息。
数据安全
  • 所有识别都在你自己的电脑上完成，PDF 和数据不会上传到任何服务器
  • 数据保存在本浏览器中，换电脑不会跟着走；重要数据请及时导出 CSV 留存
常见问题
  • 拖不进文件？改点「选择 PDF 文件」按钮，或用 Chrome / Edge 打开
  • 显示「未识别」？多为扫描件，直接在表格里手动补录即可
  • 重复发票？紫色行即为重复提醒，点「删除重复」可按组删除（默认删掉每组靠后的那条，删错可顶部撤回）
